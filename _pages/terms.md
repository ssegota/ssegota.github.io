## Privacy Policy

This is a personal academic website. It does not use analytics, advertising or tracking cookies, it
does not run a comment system, and it does not ask you for any personal information.

The site is hosted on [GitHub Pages](https://pages.github.com/). As with any web server, GitHub records
technical information about requests made to the site (such as IP address, browser type, referring page
and timestamp) for security and operational purposes. This data is processed by GitHub and is not
accessible to, or used by, the author. See the
[GitHub Privacy Statement](https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement)
for details.

Some pages link to external services (publisher pages, course websites, Google Scholar, ORCID, GitHub and
similar). Once you follow such a link, the privacy policy of that service applies.

If you contact the author by e-mail, the message and address are used only to reply to you.
